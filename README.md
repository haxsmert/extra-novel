# extra-novel：《爵迹》调研与续写

郭敬明的《爵迹》有两套互不兼容的版本，两套都没写完。这个仓库做了两件事：

1. **调研**：查清旧版、新版各自写到了哪里、留下了哪些没解开的伏笔，以及它被指「疑似抄袭」的对象与证据。
2. **续写**：从故事实际停下的地方接着写「剧情介绍」，一直写到完结，并逐条回收原作的伏笔。

> 续写部分是同人性质的创作，与原作者无关。原作小说的版权属于原作者；调研时抓取的原文只用于研读，没有放进仓库，档案里只保留了用于核对的短引。

## 三分钟读完

**故事停在哪。** 旧版走得最远：第一部《临界·爵迹》上下册写完了水源篇，第二部《爵迹·风津道》2011 年起在杂志上连载，到第十二回《觉醒者的悲鸣》就停了，从未出书。最后一个镜头是：地底洞穴里，吉尔伽美什与风后同时下令先杀特蕾娅；城外密林里，鬼山莲泉感到「有一个极其巨大的东西觉醒了」。2016 年起的新版三部曲是把旧版第一部推倒重写，并没有写到风源篇，只在结尾抛出了三个关于多年以后的预告：幽灵防御、饥饿少女、长眠者。

**续写怎么接。** 以旧版为脊、新版为翼：从《风津道》第十二回的最后一个镜头接起，把新版那三项预告和几样不冲突的新设定并了进来。理由与取舍见
`continuation/00-续写口径与设计.md`

**续写写了什么。** 四块，共四十八个章回（含各部尾声与终章），外加各部的梗概与清点：

| 顺序 | 内容 | 文件 |
|---|---|---|
| 一 | 把停更的《风津道》写完：第十三回至第二十四回，尾声 | `continuation/01-第二部后半-风津道.md` |
| 二 | 六年后，水源本土之战：幽灵防御、饥饿少女、长眠者 | `continuation/02-第三部-亡灵海.md` |
| 三 | 火源与地源：最后五把剑，十二枚瞳孔 | `continuation/03-第四部-烬与壤.md` |
| 四 | 终局与终章 | `continuation/04-终部-零度.md` |

**伏笔回收得怎么样。** 旧版原文里梳理出 153 条悬念：56 条原作后文自己已经回答，70 条由续写在正文里回收，16 条只在设定层面给了答案，11 条没有回收。逐条对照见
`continuation/99-伏笔回收对照表.md`

**疑似抄袭的对象。** 见报的指控始于 2010 年 8 月，主要对象是 TYPE-MOON 的 Fate/stay night；社区后来的逐条分析认为框架级的来源是两部——Fate 系列与八木教广的《大剑》，另有若干作品贡献了零星桥段，也有几条流传很广的指控经查不成立。没有任何法院就《爵迹》作出过抄袭认定；被法院认定抄袭的是同一作者的《梦里花落知多少》。详见
`research/06-疑似抄袭对象.md`

## 怎么读

- 只想看故事：按 `continuation/01` 到 `04` 的顺序读。没读过原作也能读，但先看一眼 `research/02` 末尾的「故事中断点快照」会顺很多。
- 想知道每个设定是原作的还是续写的：`continuation/00` 的「世界的真相」一节，每一层后面都挂着它所回收的原作伏笔；原作的部分在 `research/04` 与 `05` 里都能查到出处和原文短引。
- 想换一种接法（纯旧版线，或从新版《冷血狂宴》结尾接）：`continuation/00` 第一节末尾写了各需要改动多少。

## 关于可信度

调研遵守两条约束：搜索引擎的摘要不算证据，每条事实都回到了原始页面；子代理的转述不算证据，旧版档案里近千条原文短引全部用脚本逐字回查过原文。新版三部曲的正文没有拿到，相关内容全部标为二手，互相矛盾的地方标了「存疑」。
